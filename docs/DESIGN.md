# 设计规范

> 实现：`app/src/main/java/com/memorypalace/ui/Theme.kt`（唯一 token 来源）
> 规则：新 UI 只允许引用本文件的常量，不写字面量。

## 为什么要有这份规范

没有专职设计师，视觉分的 15 分拿不到满。但**一致性是视觉分的下限保障** —— 三个窗口、四种卡片状态、三种褪色档位，如果每处颜色和字号都不一样，评委看到的是"业余"，不是"极简"。

所以策略是：**把设计数字化，让机器替人守一致性。** 规范的价值不在于它多好看，而在于它能被代码强制执行。

## 1. 色板

| Token | 值 | 语义 | 用在哪 |
|---|---|---|---|
| `TextPrimary` | `#E8EAF0` | 主文字 | 卡片正面、标题 |
| `TextSecondary` | `#9AA3B2` | 次文字 | 说明、注释、辅助信息 |
| `Accent` | `#FFC107` | 琥珀：强调 / 到期 | 到期队列数字、当前操作 |
| `Info` | `#7CD4FD` | 青：进行中 | 复习中状态、当前卡 |
| `Success` | `#8BE9A8` | 绿：记得牢 | 队列清空、未逾期 |
| `TimeMachine` | `#FF79C6` | 粉：时间机器 | 偏移态、跳转中提示 |
| `Warning` | `#FFB86B` | 橙：正在遗忘 | 逾期标签 |
| `FadedMid` | `#B0BEC5` | 褪色中档 | 文字 0.33–0.66 |
| `FadedDeep` | `#6B7280` | 褪色深档 | 文字 > 0.66 |
| `SurfaceDark` | `#12141A` | 深色信息块底 | 事件日志 |

### 褪色档位必须与算法阈值一致

`FadedMid` / `FadedDeep` 的切换阈值不是随手定的 —— 它来自 `core/schedule/MemoryStrength.tier()` 的 0.33 / 0.66 分界。**改阈值必须同时改 core 与 Theme.kt 两处**，否则视觉与"遗忘程度"的说法会脱节。

## 2. 字号阶梯

| Token | 值 | 用途 |
|---|---|---|
| `Display` | 32sp | 面板大标题、复习卡正面 |
| `Title` | 26sp | 窗口标题 |
| `CardFront` | 22sp | 锚定卡正面 |
| `Section` | 20sp | 区块标题（到期队列 / 时间机器 / 导入确认） |
| `BodyLarge` | 18sp | 正文大 |
| `Body` | 16sp | 正文 / 按钮 |
| `BodySmall` | 14sp | 列表行 |
| `Caption` | 13sp | 辅助说明 |
| `Caption2` | 12sp | 最弱说明 |

规则：行高统一 = 字号 × 1.3（在 `MpText` 里实现，不逐处设置）。

## 3. 间距阶梯

| Token | 值 | 用途 |
|---|---|---|
| `Xs` | 4dp | 极小间隔 |
| `Sm` | 6dp | 列表行距 |
| `Md` | 12dp | 按钮间距 |
| `Lg` | 14dp | — |
| `Xl` | 16dp | 区块间距 |
| `PanelMain` | 36dp | 书房面板内边距 |
| `PanelCard` | 28dp | 随身卡面板内边距 |
| `CardAnchor` | 16dp | 锚定卡内边距 |

规则：面板内边距比卡片内边距大一档 —— 面板是"容器"，卡片是"内容"，容器应该更空。

## 4. 圆角

| Token | 值 | 用途 |
|---|---|---|
| `Block` | 8dp | 信息块圆角 |

只保留一个圆角值。项目里没有卡片堆叠的容器形态，多档圆角只会制造不一致。

## 5. 三窗的角色分配

| 窗口 | 内容密度 | 视觉重心 | 理由 |
|---|---|---|---|
| 书房看板 | 高（队列、导入、时间机器、日志） | 信息 | 管理面，需要一屏看全 |
| 随身复习卡 | 极低（正面/背面/自评） | 单卡 | 复习时注意力全在内容上 |
| 房间层锚卡 | 中（正面/背面/状态/入口） | 空间 | 卡片是"物件"，不是"界面" |

**规则**：书房面板可以密，随身卡必须空。随身卡里多放一个统计数字，复习时就少一分注意力。

## 6. 褪色视觉规则

| 状态 | 不透明度 | 文字色 | 标签 |
|---|---|---|---|
| 未到期 | 1.0 | 白 | 记得牢 · N 天后到期 |
| 逾期中 | 1 − 0.7×fade | 中灰 → 深灰 | 正在遗忘 |
| 逾期满间隔 | 0.3 | 深灰 | 快忘了 |
| 复习中·当前卡 | 1.0 | 青 | ▶ 前缀 |
| 复习中·其他卡 | 上述 × 0.3 | 同上 | — |

不透明度下限 0.3 —— 褪色是提示不是隐藏，卡片不能淡到看不见（否则用户以为数据丢了）。

## 7. 冷启动占位（M12）

非透明主题才有 starting window。`Theme.MpSplash` 用 `windowBackground` 让系统在进程起来之前先画一屏，避免模拟器冷启动 12 秒的黑屏被误认为"应用挂了"。

占位页在空间音频与三窗就绪后自动关闭，20 秒超时兜底（异常时不至于把 splash 永久留在场上）。

## 8. 禁止事项

- 禁止在 UI 代码里写字面量颜色/字号/间距 —— 一律引用 `Theme.kt`
- 禁止用模板化的逐行注释与分隔线（代码风格要求，见 README）
- 禁止引入第二套色板（"深色主题"等）—— 评委只跑默认环境
