## 2. 每个数字的来源（不许含糊）

### 创新 20–23（不是 25）

**拿不到 25 的原因**：空间锚定 + 间隔重复 + MR 三者结合的思路本身是清晰的，评委看第一眼能理解，但"清晰"不等于"首创"。扣分点在两处：

1. 记忆宫殿（loci method）是两千年古法，把知识绑到空间位置不是新发明
2. Anki 的 SM-2 调度是 1987 年的公开算法

**我们的应对**是把创新点从"概念"移到"实现层的完整性"：锚定用系统级 WorldTracking（不是视觉匹配），杀进程重进可找回（实测 drift=0.0m）；遗忘曲线驱动**空间外观**而不只是排期；空间音频从锚点位置发声而不是屏幕提示。这三件事同时做到的产品，XR 同类里目前没有（见 `docs/COMPETITORS.md`）。

**下调触发条件**：若竞品调研中发现已有产品同时做了"真实空间锚定 + 间隔重复调度"，创新分直接降到 18–20。

### 功能 20–23（不是 25）

**功能分的实际内容**：不是"有几个按钮"，是**闭环是否成立**。本项目当前状态（M13）：

| 闭环环节 | 状态 | 证据 |
|---|---|---|
| 导入牌组 | ✅ CSV / TXT / apkg 三格式离线解析 + 字段映射确认页 | `docs/M5-IMPORT-PIPELINE-TEST.md`、`M8-IMPORT-CONFIRM-TEST.md` |
| 空间锚定 | ✅ 放卡 → 杀进程 → 重进 → 找回，drift 0.0m | `docs/ANCHOR-M2-TEST.md` |
| 遗忘曲线调度 | ✅ SM-2 改进版，42 例单测 | `docs/ALGORITHM.md` |
| 看得见的遗忘 | ✅ 褪色可视化，快进 7 天集体褪色 | `docs/M6-TIME-MACHINE-TEST.md` |
| 复习流 | ✅ 队列 → 翻面 → 自评 → 调度更新 | `docs/M4-REVIEW-FLOW-TEST.md` |
| 空间音频引导 | ⚠️ M13 已实现，模拟器未验（需真机） | 待补真机录屏 |
| 每日真实使用 | ❌ 11/28 起才开始 | 无 |
| 非开发者 7 天连续 | ❌ 11/23 起约人 | 无 |

**"可用时长"是这块的软肋**：现场无法证明"你真的每天用"。唯一的对冲是使用记录 + 循环设计（时间机器把抽象算法变成可感知的体验）。**每日使用记录断签一次，这块的证据链就断一次** —— 11/28 是硬动作，不是"有空就做"。

**扣分点**：空间音频未在真机验证前，空间引导这半条链是纸面的。

### 交互 12–14（不是 15）

**拿不到 15 的原因**：模拟器无法驱动 3D 空间按钮（官方明示），多窗口拖动/缩放、手势这些**招牌交互在模拟器上一秒都演示不了**。这是环境限制，不是实现缺失，但评委看到的就是"没演示出来"。

**已拿到分的部分**：双态架构（Shared Space 多窗口 / Full Space 房间层）是平台级的正确用法，官方 Sample 的结构；11/07 实测确认窗口存活、Stage 重建、双态切换可行（`docs/DUAL-STATE-TEST.md`）。

**空间音频这一项在 11/30–12/2 之前是纸面的**，M13 把它落地了，但需要真机确认声场正确。

### 视觉 11–13（不是 15）

**明说不追满分**：无专职设计师，从零做视觉不现实。这 11–13 分的拿法是**一致性** —— 三个窗口、四种卡片状态、三种褪色档位共用一套数字化 token（`docs/DESIGN.md`），让评委看到的是"极简克制"而不是"业余"。视觉是保下限项，扣分最多 4 分不影响名次。

### 完成度 9（不是 10）

**这一项必须拿满，是白送分**。扣 1 分的保守估计，理由是 README 的"30 秒运行指南"在干净机器上的一次跑通记录还需在 12/8–12/11 补（本地已跑通，但没在"干净电脑"上验证过）。

**已锁定的加分项**：Apache-2.0 开源公开仓（评分表明确写"开源"）、42 例 core 单测全绿、commit 记录如实反映人机协作过程。

### 路演 6–9（不是 10）

**完全取决于两件不在我们手上的事**：

1. **真机着落**（借测判定日 11/20）—— 决定视频说服力镜头与决赛演示证据链
2. **12/25 陌生房间实测 ≥9/10** —— 决定决赛现场锚定会不会当场翻车

**"未解决前按 6–7 计"是诚实下限**：拿不到真机就只能投屏模拟器路演（§5.2 无真机方案），那个口径下评委看到的画面质感明显弱于真机。

**这块最值钱的一句**是路演里"空间会主动叫你来"的那一刻 —— 但它只在真机上成立。

## 3. 诚实声明（对外材料统一口径）

1. 视觉 15 分我们拿不到满，策略是规范数字化 + 极简路线保下限
2. 功能分的"可用时长"只能用使用记录与循环设计对冲，无法现场证明
3. 空间音频在真机验证前是纸面能力
4. 模拟器无法驱动空间按钮，空间交互证据一律走"应用内测试入口录屏 + 真机补证"，不承诺"模拟器可演示完整交互"
5. 模拟器录制的画面一律带"模拟器录制"角标，不伪造真机画面

**这两个缺口已定价、已对冲，不伪装满分。** 评委看 README 翻 git log 时，两者一致才是加分而不是穿帮。
