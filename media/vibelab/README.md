## 复现方式

所有中间文件在 `/e/tmp/vibelab/`，仓库内不留临时产物。核心命令（已 `cd` 到工作目录，
因为 ffmpeg 的 `fontfile` 路径不能含空格和冒号，必须用相对路径）：

```bash
cd /e/tmp/vibelab
cp <repo>/media/work/fonts/NotoSansSC.otf .

# 例：详情页图 3
ffmpeg -y -i src/v09.jpg \
  -vf "crop=1600:900:0:380,scale=2560:1440,\
       drawbox=x=0:y=1176:w=2560:h=264:color=0x0B0D12@0.90:t=fill,\
       drawbox=x=0:y=1176:w=2560:h=6:color=0xFF79C6@0.9:t=fill,\
       drawtext=fontfile=NotoSansSC.otf:textfile=txt/d3.txt:fontcolor=0xE8EAF0:fontsize=58:x=96:y=1252,\
       drawtext=fontfile=NotoSansSC.otf:textfile=txt/dfoot.txt:fontcolor=0x6B7280:fontsize=30:x=96:y=1350" \
  -pix_fmt yuvj420p -q:v 2 -frames:v 1 detail-3.jpg
```

中文文字一律走 `drawtext` + `fontfile`（Noto Sans SC），**未使用 libass subtitles**——
本机 libass 会静默丢字。
